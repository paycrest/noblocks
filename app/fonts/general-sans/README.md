# General Sans (Fontshare)

Official woff2 files from the Fontshare complete package
(`https://api.fontshare.com/v2/fonts/download/general-sans`), copied
unmodified. Only Regular (400), Medium (500) and Semibold (600) — the
weights used in the KAN-975 KYC upgrade modals — are included.
